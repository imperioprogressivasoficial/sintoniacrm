Conecte o seu sistema à Sintonia

Leia e crie contatos, mande mensagens de WhatsApp, mova leads no funil, aplique tags, marque horários e receba avisos em tempo real. Tudo pela API v1, pelos webhooks ou pelo MCP, para conectar a IA (Claude, Cursor) direto no seu CRM.

Autenticação

      
Toda chamada leva a chave no cabeçalho Authorization: Bearer sk_... (ou x-api-key). A chave é da empresa: tudo o que ela lê ou muda é sempre dessa empresa. A chave inteira aparece uma vez só, quando é criada; guarde num cofre de segredos (variável de ambiente), nunca no código do site ou do app.

      
Chave vazou? Revogue na hora em Integrações › Chaves de API e crie outra. A revogação vale em segundos.

      
Escopos (permissões)

      
Cada chave tem escopos por recurso: recurso:ler e recurso:escrever. Escrever inclui ler. Sem o escopo, a resposta é 403 sem_permissao, com o escopo que faltou.

Paginação por cursor

      
As listas devolvem { "dados": [...], "proximoCursor": "..." }. Para a próxima página, repita a chamada com ?cursor= igual ao proximoCursor. Quando ele vier null, acabou. limite vai de 1 a 100 (padrão 25).

      
Limite de chamadas

      
Cada chave tem um limite por minuto (padrão 60, ajustável ao criar). Toda resposta traz X-RateLimit-Limit, X-RateLimit-Remaining e X-RateLimit-Reset (segundos até abrir vaga). Passou do limite: 429 limite_excedido com Retry-After.

Webhooks

      
Cadastre o endereço do seu sistema (precisa ser https e público) e escolha os eventos. A cada evento a Sintonia faz um POST com JSON. Responda 2xx em até 10 segundos; o processamento pesado, faça depois (numa fila sua).

      
Corpo de todo evento
{
  "id": "evt_3f2a9c1e8b7d4a5f9e0c1b2a3d4e5f60",   // o mesmo em todas as tentativas: use para não processar duas vezes
  "tipo": "mensagem.recebida",
  "criadoEm": "2026-11-20T14:03:11.000Z",
  "empresaId": "sua-empresa",
  "dados": { ... }
}

      
Cabeçalhos: Sintonia-Evento, Sintonia-Evento-Id, Sintonia-Entrega, Sintonia-Tentativa e Sintonia-Assinatura.

Validar a assinatura

      
Sintonia-Assinatura: t=<segundos>,v1=<assinatura>. A assinatura é o HMAC-SHA256 (hexadecimal) do texto t + "." + corpo cru, com o segredo do webhook (whsec_...). Compare em tempo constante e recuse se t tiver mais de 5 minutos. Use o corpo cru, antes de converter o JSON.

      

      
Node.js (Express)
import crypto from 'node:crypto';
import express from 'express';

const app = express();
const SEGREDO = process.env.SINTONIA_WEBHOOK_SEGREDO; // whsec_...

app.post('/webhooks/sintonia', express.raw({ type: 'application/json' }), (req, res) => {
  const cab = req.get('Sintonia-Assinatura') || '';
  const partes = Object.fromEntries(cab.split(',').map((p) => p.trim().split('=')));
  const t = Number(partes.t);
  const esperado = crypto.createHmac('sha256', SEGREDO).update(`${t}.${req.body}`).digest('hex');
  const recebido = Buffer.from(partes.v1 || '', 'hex');
  const ok = recebido.length === 32
    && crypto.timingSafeEqual(recebido, Buffer.from(esperado, 'hex'))
    && Math.abs(Date.now() / 1000 - t) <= 300;
  if (!ok) return res.status(400).send('assinatura inválida');

  const evento = JSON.parse(req.body.toString('utf8'));
  // Já processou este evento.id? Ignore (pode chegar de novo numa nova tentativa).
  console.log(evento.tipo, evento.dados);
  res.sendStatus(200);
});

app.listen(3000);

      
Python (Flask)
import hashlib, hmac, json, os, time
from flask import Flask, abort, request

app = Flask(__name__)
SEGREDO = os.environ["SINTONIA_WEBHOOK_SEGREDO"].encode()  # whsec_...

@app.post("/webhooks/sintonia")
def sintonia():
    corpo = request.get_data()  # corpo cru, em bytes
    partes = dict(p.strip().split("=", 1) for p in request.headers.get("Sintonia-Assinatura", "").split(",") if "=" in p)
    t = int(partes.get("t", "0"))
    esperado = hmac.new(SEGREDO, f"{t}.".encode() + corpo, hashlib.sha256).hexdigest()
    if not hmac.compare_digest(esperado, partes.get("v1", "")) or abs(time.time() - t) > 300:
        abort(400)

    evento = json.loads(corpo)
    # Já processou evento["id"]? Ignore.
    print(evento["tipo"], evento["dados"])
    return "", 200


      
Tentativas e desligamento

      
Se o seu sistema não responder 2xx (ou demorar mais de 10 s), a Sintonia tenta de novo com espera crescente: 1 min, 5 min, 30 min, 2 h, 5 h, 10 h e 24 h (8 tentativas no total). Redirecionamentos não são seguidos. Depois de 20 falhas seguidas, o webhook é desligado sozinho e a gestão recebe um aviso no sino; ligue de novo na tela quando o seu sistema voltar. Na tela dá para ver cada entrega (status, resposta, tempo), Reenviar qualquer uma e Enviar teste.

      
Por segurança, a Sintonia não chama endereços internos: localhost, redes privadas (10.x, 172.16–31.x, 192.168.x), link-local e os endereços de metadados de nuvem são bloqueados, inclusive quando o nome do site aponta para eles.
